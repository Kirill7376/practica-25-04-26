# LLM Chat — ваш личный ассистент с поиском в интернете

Этот проект запускает нейросеть прямо на вашем компьютере.  
Вы можете общаться с ней, давать задания, спрашивать советы, загружать файлы (код, текст) для анализа.  
Если модель чего-то не знает, она **сама найдёт ответ в интернете** и продолжит разговор.

## Что умеет этот чат

- Отвечать на вопросы и вести беседу
- Автоматически искать информацию через DuckDuckGo, когда знаний не хватает
- Читать текстовые и кодовые файлы такие как .txt, .py, .json, .cpp и др.
- Менять тему тёмная/светлая, температуру, системный промпт под себя
- Сохранять и пересматривать старые диалоги
- Перегенерировать ответ, если он не понравился
- Останавливать генерацию на середине

## Технологии

- **Бэкенд**: 
`Python 3`
`FastAPI`
`SQLAlchemy`
`SQLite`
`llama-cpp-python`
- **Фронтенд**: `Flutter Web`
- **Модель**: любая совместимая с ChatML например: `Gemma 3`, `Gemma 4`, `Mistral`, `Phi` и др. в формате `GGUF`
- **Поиск**: `DuckDuckGo`

## Что нужно, чтобы запустить

- **Windows 10/11** на Linux/Mac тоже можно, но инструкция для Windows
- Установленный **Python 3.10 или новее** [скачать с python.org](https://www.python.org/downloads/)
- Установленный **Flutter SDK** [инструкция по установке](https://docs.flutter.dev/get-started/install/windows)
- **Минимум 8 ГБ оперативной памяти** (для 4B модели)
- **Около 5 ГБ свободного места на диске**

## Установка и запуск

### 1. Скачайте проект
```bash
git clone https://github.com/Kirill7376/llm-chat.git
cd llm-chat
```
Или просто скачайте ZIP-архив и распакуйте в любую папку.

2. Настройте бэкенд - Python
Откройте терминал командную строку в папке backend.

# Создаём виртуальное окружение
bash
```python
python -m venv venv
```

# Активируем его - Windows
```python
venv\Scripts\activate
```
# На Linux/Mac: source venv/bin/activate

# Устанавливаем все необходимые библиотеки
```python
pip install -r requirements.txt
```
3. Скачайте модель
Перейдите в папку backend/models/.

Скачайте файл модели в формате GGUF.
Рекомендуем: `Gemma-3-4B-VL-it-Gemini-Pro-Heretic-Uncensored-Thinking_Q4_k_m.gguf`
Ссылка для скачивания:
https://huggingface.co/Andycurrent/Gemma-3-4B-VL-it-Gemini-Pro-Heretic-Uncensored-Thinking_GGUF/resolve/main/Gemma-3-4B-VL-it-Gemini-Pro-Heretic-Uncensored-Thinking_Q4_k_m.gguf

Или же запустите файл `download_model.py` для автоматического скачивания модели.

ПРЕДУПРЕЖДЕНИЕ
Прежде чем запускать автоматическое скачивание модели перейдите по пути куда распаковали проэкт в папку `backend`

НАПРИМЕР:
`C:\...\backend\`

И выполните команды:

```python
python -m venv venv
venv\Scripts\activate
python download_model.py
```

Убедитесь, что в файле backend/model.py строка MODEL_PATH указывает на этот файл:

```python
MODEL_PATH = "models/имя-вашего-файла.gguf"
```
Или же например:
```
MODEL_URL = "https://huggingface.co/Andycurrent/Gemma-3-4B-VL-it-Gemini-Pro-Heretic-Uncensored-Thinking_GGUF/resolve/main/Gemma-3-4B-VL-it-Gemini-Pro-Heretic-Uncensored-Thinking_Q4_k_m.gguf"
```
4. Запустите бэкенд
```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```
Если всё хорошо, вы увидите строчку:

```text
INFO:     Uvicorn running on http://0.0.0.0:8000
```
5. Настройте и запустите фронтенд (Flutter)
Откройте новый терминал в папке chat_app:

```bash
flutter pub get
flutter run -d web-server --web-port=8080
```
Когда появится сообщение, что сервер запущен, откройте браузер и перейдите по адресу:
`http://localhost:8080`

Быстрый запуск (Windows)
Дважды кликните по файлу `all.bat` в корне проекта.
Откроются два окна терминала: первое запустит бэкенд, второе — фронтенд.
Сам чат откроется в браузере по адресу `http://localhost:8080`.

Важно: после запуска первого сообщения придётся подождать `30–90` секунд – модель загружается в память. Дальше ответы будут быстрее.

Как пользоваться
Обычный чат
Просто пишите сообщение и нажимайте на кнопку отправки.

Поиск в интернете
Модель сама решит, когда нужно что-то найти — вы увидите это в ответе.

Если хотите принудительно задать поиск, напишите: `/search` ваш запрос

Загрузка файлов
Нажмите на иконку скрепки (справа от поля ввода) и выберите любой текстовый файл.
Его содержимое сразу вставится в сообщение. Модель сможет объяснить код, найти ошибки, проанализировать логи.

Настройки
В левом меню выберите Настройки:

Тёмная тема — переключается мгновенно

Имя ассистента — можно задать, как модель будет подписываться

Температура `0…1.5` — чем ниже, тем более точные и предсказуемые ответы

Максимум токенов — ограничивает длину ответа `100-2000`

Системный промпт — главная инструкция для модели. По умолчанию: «Ты — вежливый русскоязычный ассистент. Отвечай кратко, по делу.»

История диалогов
Все беседы сохраняются автоматически. Вы можете открыть старый диалог из списка (левое меню → История) и продолжить общение. Кнопка `+` создаёт новый чат.

Кнопки в сообщениях
Копировать (иконка листа) – копирует всё сообщение

Перегенерировать (иконка обновления) – удаляет последний ответ и создаёт новый на тот же запрос

Выделение мышкой – можно выделить любой кусок текста и скопировать через Ctrl+C

Как перенести на другой компьютер
Скопируйте папку проекта или клонируйте репозиторий.

Установите `Python` и `Flutter`.

В папке `backend` создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
Скачайте модель и положите в `backend/models/`.

В папке `chat_app` выполните:

```bash
flutter pub get
```
Запускайте бэкенд и фронтенд как обычно.

Возможные проблемы
Модель отвечает ерунду
→ Уменьшите температуру до `0.3–0.5` в Настройках. Проверьте системный промпт.

Первый ответ очень долгий
→ Это нормально: модель загружается в память. Дождитесь, дальше будет быстро.

Ссылки из поиска ведут на 404
→ Результаты поиска могли устареть. Попробуйте переформулировать запрос или задать его позже.

Ошибка `Failed to fetch`
→ Убедитесь, что бэкенд запущен и доступен по адресу http://localhost:8000
